# Moribin — 恒星間入植ゲーム

2次元の恒星間入植ゲーム(試作)。依存ライブラリなし、ブラウザだけで動く。

```sh
npm start            # http://localhost:8000 を開く (python3 -m http.server)
npm run check        # 生成ロジックと入植ロジックの検証
```

URL に `?seed=123` を付けると同じ銀河を再現できる。

## 現在の機能

**星間マップ** (`g` キー)
- 400星を自動生成。**最近接の星までの平均距離がちょうど 4 ly** になるよう全体をスケーリング。
- 太陽系が中心(実データ)。ドラッグで移動、ホイールでズーム、クリックで選択、ダブルクリックで星系を開く。
- 選択した星を中心に 4/8/16/32/64 ly のリング。ホバーで距離と光速での所要年数を表示。

**星系マップ** (`s` キー)
- 恒星・伴星・惑星・小惑星帯を軌道上に表示(軌道半径は対数スケール)。ハビタブルゾーンと雪線つき。
- 天体をクリックで詳細(質量・半径・重力・温度・大気圧・地表・入植適性)。

**入植** — 2種類
- **宇宙ステーション建設**: 惑星・小惑星帯・恒星のどれの周回軌道にも建設可能。
- **惑星入植**: 固体表面の天体のみ。適性(不可/困難/可/良好)が「困難」以上のとき可能。
- 入植船は**光速**(`src/game.js` の `SHIP_SPEED`)で航行。出発地は入植済みの星系から選ぶ。

## 現実準拠の部分
- スペクトル型の比率: M 73% / K 12% / G 7.6% / F 3% / A 0.6% / B 0.13% / O 0.00003% / 白色矮星 3.5%。
- 質量-光度関係、半径、表面温度、色(黒体放射)を質量から計算。
- 連星・多重星 (約3割)。伴星が近いと惑星の安定軌道が制限される。
- 雪線(岩石/巨大ガス・氷)、ハビタブルゾーン、平衡温度、大気保持、温室効果、潮汐固定。
- 地球型惑星は約 1〜2% の星系にしかない。
